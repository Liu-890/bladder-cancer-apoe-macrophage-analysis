# Bladder Cancer APOE Macrophage Analysis

This repository contains the R script used to generate figures for the manuscript:

> Integrative Single-Cell and Spatial Transcriptomic Analyses Reveal an APOE-Associated Macrophage Programme Linked to Poor Prognosis and Epithelial Remodelling in Bladder Cancer

## Repository contents

- `Figure_plotting.R`: R script used for manuscript figure generation.

## Data availability

This repository does not contain raw patient-level data. Public datasets analysed in this study are available from the NCBI Gene Expression Omnibus and The Cancer Genome Atlas.

The single-cell RNA-sequencing datasets are GSE129845, GSE135337, GSE175526, GSE211388, GSE222315, GSE269877, GSE310557 and GSE326225. The spatial transcriptomic dataset is GSE238145. External validation datasets are GSE32894 and GSE13507. TCGA-BLCA transcriptomic and clinical data are available through The Cancer Genome Atlas.

## Reproducibility

Install R and the packages required by `Figure_plotting.R`, obtain the public data listed above, and run the script after setting the relevant input and output paths.
